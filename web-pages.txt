 To deploy on GitHub Pages

  1. Commit and push the docs/ folder
  2. In your repo on GitHub: Settings → Pages → Source → Deploy from
  branch main, folder /docs
  3. The site goes live at https://ricauc.github.io/NULL_MESH/

  To preview locally right now, open the file directly in a browser
  (open docs/index.html in Terminal) — no server needed.

  ---
  To fill in YouTube IDs

  Search TODO in docs/index.html — there are 18 marked entries. For
  each one, replace TODO_IDENTIFIER in the href with the actual
  11-character YouTube video ID (the v= part of the URL).
